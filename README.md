# Tende

Tende is a simple student finance tracker.

It helps students record expenses, check how much they have spent, and manage a monthly budget.

## Main Features

- Add an expense
- View expenses
- Edit an expense
- Delete an expense
- Search expenses
- Filter expenses by category
- Sort expenses
- View total spending
- View monthly budget
- Save data in the browse

## Main Sections

- Dashboard
- Records
- Add Record
- Settings
- About

## Data Model

Each expense will have:

- id
- description
- amount
- category
- date

Example:

```json
{
  "id": 1,
  "description": "Lunch",
   "amount": 5000,
  "category": "Food",
  "date": "2026-10-14"
}
